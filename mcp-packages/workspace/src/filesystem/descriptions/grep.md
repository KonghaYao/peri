Search file contents using regex.

Directory walks skip hidden entries and honor ignore rules; an explicit file path bypasses those exclusions. A saved result contains only collected output, not necessarily all matches; narrow or partition the search for complete counts.

Output modes: Match lines, matching files, matching-line counts by file in single-line mode (not occurrences), or nonmatching files. The limit counts output lines in content mode and files otherwise; zero removes only the count limit, not the byte cap.
