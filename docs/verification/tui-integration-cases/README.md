# TUI 集成测试用例

> 状态：待执行的集成测试用例目录，不记录通过情况。本文是 TUI 用户可观察集成验收场景的权威目录；工程规则以[测试规范](../../standards/testing.md)和[TUI 规则](../../standards/tui.md)为准，交互目标见[设计文档](../../design/tui-chat-workbench.md)。实际通过情况须由执行证据证明。

## 执行口径

1. 使用当前构建的 Peri TUI、真实 ACP transport 和终端；模型响应、工具输入与故障可由本地可控服务提供。隔离 HOME、配置、缓存与工作目录，保留终端录制、事件顺序及必要的持久化证据。
2. 每条用例独立启动或重置会话，按描述完成操作，再同时核对屏幕结果与实际请求、事件或持久数据。屏幕上的用户 prompt 回显不能充当模型回复证据。
3. 用例编号是全目录 P0 执行顺序；先执行较低编号，区域文件内也使用有序列表。一次执行的结果和失败证据写入测试报告，不回填本目录。可参照 [E2E 运行指南](../../../e2e/CLAUDE.md) 自动化。

## P0 执行顺序

1. [启动与会话](01-session.md)：P0-01～P0-05。先确认会话身份、历史与故障边界。
2. [输入与消息时序](02-prompt-order.md)：P0-06～P0-12。重点防止新 prompt 上移、重复投递及旧终态污染。
3. [流式回答与工具](03-stream-tools.md)：P0-13～P0-17。确认可见输出顺序、工具结果和取消终态。
4. [Subagent 与后台任务](04-subagent.md)：P0-18～P0-23。确认详情非空、父子归属与结果回送。
5. [审批与问答](05-interactions.md)：P0-24～P0-27。确认响应只交给正确的运行任务。
6. [消息区与覆盖层](06-transcript-ui.md)：P0-28～P0-31。确认滚动、弹窗和窄屏下仍能读写。
7. [执行、历史与故障边界](07-execution-boundaries.md)：P0-32～P0-37。确认旧历史不复活、预算及错误可诊断、准备阶段可取消。
8. [后台任务生命周期](08-background-lifecycle.md)：P0-38～P0-40。确认投递重试、预算边界与取消结算。
9. [长会话与资源稳定性](09-performance.md)：P0-41～P0-43。确认缓存淘汰、长流式与历史增长下的行为和成本。
10. [配置与能力开关](10-configuration.md)：P0-44。确认 Plugin 失败和迟到结果的会话归属。
11. [消息内容显示](11-transcript-display.md)：P0-45～P0-53。确认渲染类型、Markdown、折叠与复制。
12. [输入区、状态栏与后台任务栏](12-composer-status.md)：P0-54～P0-57。确认可见状态与输入内容。
13. [面板与详情显示](13-panel-display.md)：P0-58～P0-61。确认选择身份、会话数据与保存反馈。
14. [阻塞交互与弹出层显示](14-popup-display.md)：P0-62～P0-65。确认审批、认证、确认与问答的可读性。
15. [浏览态与整体布局](15-browse-layout.md)：P0-66～P0-67。确认新输出提示和宽终端命中。
16. [Subagent 长期后台 shell](04-subagent.md)：P0-68。确认 child 提交时及时收到 shell 任务事实，并在自行结束任务后交付。
17. [Subagent 流断提醒归属](04-subagent.md)：P0-69。确认子任务流断提醒显示于父视图、不进入父模型上下文，只由 child 消费并续跑。
18. [Subagent 与后台任务](04-subagent.md)：P0-70～P0-73。确认并行任务的活跃与静默可辨、传输故障不静默、排队回执不冒充消费、任务与线程身份可区分。
19. [后台任务生命周期](08-background-lifecycle.md)：P0-74～P0-76。确认取消的真实停止、终态现场保留与会话重载后的状态如实。
20. [复制通道与远程剪贴板](16-clipboard-transport.md)：P0-77～P0-80。确认本机系统剪贴板、SSH 终端 OSC 52、tmux 双路径、显式通道覆盖与远程 Ctrl+V 引导。
21. [首次配置向导](17-setup-wizard.md)：P0-81。确认预设填充、四档模型与落盘配置一致，未填 Key 不能提交。
