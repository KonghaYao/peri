# 流式输出时文本和工具调用卡片重复显示

**状态**：Fixed
**优先级**：高
**创建日期**：2026-07-18

## 问题描述

流式输出过程中，同一段内容（AI 回复的文本段落、工具调用卡片）在 TUI 界面上紧挨着重复显示了两次——前一段和后一段的字节内容完全一致。该问题每次都必现，所有轮次（turn）均受影响。文本和工具调用两类内容都会重复。

## 症状详情

| 维度 | 观察到的现象 |
|------|--------------|
| 重复内容 | 文本段落 + 工具调用卡片，两类都出现 |
| 重复形式 | 完全相同的两段紧挨着连续出现 |
| 复现频率 | 每次流式输出必现 |
| 影响范围 | 所有轮次 |
| 与模型关系 | 用户判断与模型无关 |

## 复现条件

- **复现频率**：必现
- **触发步骤**：发送任意 prompt 触发流式输出即可复现
- **环境**：macOS 26.5.1，Peri TUI

## 涉及文件

- `peri-acp/src/event/forwarder.rs` —— render 事件→ExecutorEvent 映射与扇出逻辑，之前已有一条 fix 注释（第 222-226 行）描述了完全相同的"双轨扇出导致 md 重复渲染"问题
- `peri-tui/src/kit/acp_events.rs` —— ExecutorEvent → VIEW_MODELS 映射
