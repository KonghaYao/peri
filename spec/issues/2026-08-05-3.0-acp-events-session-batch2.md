## 任务定义

**本批目标**：peri-acp 不再直接依赖 peri-agent / peri-middlewares / peri-lsp / peri-workflow 的业务面（仅允许依赖 peri-controller / peri-acp-types；经装配注入的类型除外）。

**验收标准（分波 2）**：
- executor 编排薄壳 / `run_session_loop` 调用 → `Controller.run_session`；AgentEventHandler / 事件订阅 → Controller 事件弹出订阅
- AgentCancellationToken / CronOwner / goal / inbox / interaction 等直接依赖 → Controller 透传接口或装配注入
- 事件三层化收尾：v1 兼容映射保留在 ACP 协议面（peri-acp-types），发射点统一经 Controller
- 验收：peri-acp/src 中不再出现 `use peri_agent::`（测试文件允许但尽量收敛；build_v2_subagent/background 等已迁出后不得回引）

## 审批结论（首次，REJECT）

审批人核验后 REJECT，三个核心未达标项：

1. **「use peri_agent::」系全路径引用规避，实质依赖未消除**：118 处 `peri_agent::` 全路径引用（非测试代码），含直接调用业务面（`run_react_loop` / `SessionFactory::spawn_subagent` / `AgentModelBridge::new` / `TaskManager::new()` 默认回退 / `build_middleware_chain`）；Cargo.toml 仍依赖 4 个业务 crate。
2. **三条事件旁路绕过 Controller**：`executor_helpers.rs:655`（Phase 2 bg event pump）、`executor.rs:700-709`（bg 命令事件泵）、`executor.rs:721-785`（Registry 事件泵）直推 `EventSink`，缺 Runtime 补打身份（违 §9 事件契约）。
3. **executor 编排薄壳未达成**：`run_session_loop` 完整编排本体仍在 ACP `host/exec/`。

**审批修复点**：
① 三条事件旁路改经 `Controller::publish_event`（带 `UnstampedEvent` 身份），消费端统一从 `Controller::subscribe` 订阅；
② 118 处全路径引用逐处裁定：直接调用业务函数应收窄为经注入的 trait/句柄，**或与任务规划者明确「过渡宿主豁免至 L5」并写回 active spec**；
③ Cargo.toml 的 4 个业务 crate 依赖随收窄移除或**列入显式豁免清单**。
