# 启动与会话

按 [总目录](README.md) 的编号执行。每条从隔离的配置和工作目录开始，除非描述要求重启。

1. **P0-01 首次启动并完成对话**
   1. 使用空 HOME、临时配置和本地模型服务启动 TUI，完成首次配置。
   2. 发送带唯一标记的请求，等待独有回复和运行状态结束。
   3. 核对模型端只收到一次请求、界面回到空闲；退出后配置已落盘，未访问真实凭据。
2. **P0-02 重启后加载历史并续聊**
   1. 完成一轮含用户、助手和工具消息的对话，记录会话 ID 后退出。
   2. 使用同一 HOME 重启，加载原会话，再提交一条新请求。
   3. 核对历史顺序及工具终态不变，新回复进入原会话；旧 Agent 运行态和 loading 不恢复。
3. **P0-03 切换会话隔离内容**
   1. 建立两个含不同唯一标记的会话，保留会话 A 的迟到通知。
   2. 通过 Threads 面板来回切换，在会话 B 续聊后释放迟到通知。
   3. 核对消息、工具和后台任务只属于当前会话，模型请求绑定 B，A 的事件不混入屏幕。
4. **P0-04 加载失败保持原会话**
   1. 准备无法加载或执行环境不可用的历史会话，保持当前会话有可见内容。
   2. 从 Threads 面板选择失败目标，观察错误，再在原会话发送消息。
   3. 核对失败提示明确、原内容与输入保留；不暗中新建会话，也不把请求发给失败目标。
5. **P0-05 清空后旧内容不再出现**
   1. 在含用户、助手和工具记录的会话准备一条可迟到的旧通知。
   2. 执行清空，发送新输入，再释放旧通知；随后重启并加载旧会话。
   3. 核对新消息区只含新会话内容、无旧 loading；新请求绑定新会话，旧历史仍可独立加载。
