## 二、跨会话共性模式

### 🔴 P0-1 Grep/Glob path 参数失效（本轮 2/5，历史 5/5 → 持续未修，工具层实锤）

- 证据：019fc059（#1→#3）`path=popup_overlay.rs` 返回 `submit_consumer_test.rs`/`mouse_router.rs`；（#16→#17）`path=…/kit/popups` 返回 `langfuse-client/src/error_test.rs`；（#18→#19）`path=…/rewind_popup.rs` 返回 `TUI-STYLE.md`、`spec/`。命中内容与各自 pattern 吻合，排除错配伪影；019fcb61（#41）`path=仓库根` 前 20 条命中全在无关 crate。
- 影响：噪音污染上下文；agent 把工具 bug 合理化为"pattern 太宽"（019fc059 #18），可能基于跨 crate 噪音得出错误结论。
- 修复方向（沿用 + 升级）：① 结果回显 `searched_in`/命中文件数（"searched 1,204 files repo-wide"）；② 命中全在请求 path 之外 → 醒目 WARNING；③ path 不可达硬报错；④ 复现单文件 pattern 含 `\|` 场景。

### 🔴 P0-2 连续无产出推测不停 + 系统提醒被忽略（本轮 3/5，历史 3/5 → 持续）

- 证据：019fcc0e 静态推测 60+ 轮、4 次 reminder 被选择性忽略（#30/#92/#107/#230），agent 自己说"需要运行时证据"却继续读代码 28 轮（#93→#120）；019fd9ec 深挖 18+ 轮，3 次提醒后继续（#77/#82/#116/#128），用户需求 100rps 早在 195rps 时已满足；019fd635 两次提醒被覆盖且两次都错（#44/#103，覆盖后 3 轮内被用户证伪）。
- 影响：每会话 20-60 轮空转 ≈ 15-25 分钟；是当前最大的单点浪费。
- 修复方向：reminder 升级为 AskUserQuestion 卡片（选项：派 explorer / 重跑拿运行时证据 / 收敛）；提醒附"已空转轮数 + 最近 3 个无结果查询 + 距用户显式需求的差距"；对"每轮有新实验数据"的假设驱动深挖与"无产出空转"区别对待。

### 🟠 P1-1 窄输出过滤器吞错误 → 全量重跑（本轮 2/5，历史 3/5 → 持续）

- 证据：019fc059 `cargo test | tail -8` 吞掉 `error[E0308]` 头（#30→#33），重跑一次全量编译；019fcc0e e2e 重跑 `grep -E "✓|×|passed"` 吞掉完整 dump（#248→#255 agent 才意识到被截断）。
- 修复方向：Bash 结果对 cargo/rustc 自动提取 `error[E…]` 块；e2e 失败重跑默认保留完整 dump；对 `tail -N`（N<30）管道警告。

### 🟠 P1-2 `git commit` 默认 15s 超时被杀 + 提交前无 fmt 预检（本轮 2/5，历史后台 15s 超时的 commit 变体）

- 证据：019fcb61 前 6 个 cargo 命令都显式设 timeout，唯独 #131 `git commit` 用默认 15s 被 lefthook 打断；019fc059 #101 同场景，超时错误提示"避免扫描大目录"与 commit 无关，agent 事前已知 lefthook 存在仍不预防。
- 连锁：fmt 未预检 → hook 失败 → 手动修 3 处（019fcb61 #137-140）或 cargo fmt 后提交再补测（019fc059 #104-106）。
- 修复方向：① 对 `git commit`/`cargo`/`npm` 等慢命令按类别预设更长 timeout；② 检测 `.lefthook.yml`/`pre-commit` 时主动提示 timeout≥120s；③ commit 失败后解析 hook 错误给出可操作建议（"fmt --check 失败，先跑 cargo fmt"）；④ 超时错误按命令类型定制提示文本。

### 🟠 P1-3 重复 Read 同一文件/同区间（本轮 4/5，历史 2/5 → 回升）

- 证据：019fcc0e `rewind_candidates.rs` 3 次（#89/#98/#259）、`rewind-v2.test.ts` ≥3 次；019fd635 `sync-to-server.sh` 2 次、`docker-compose.stress.yml` 2 次、`Dockerfile` 3 次；019fc059 全读后又 offset 重读（#7+#9）；019fcb61 scroll.rs 分 8 次局部读、区间重叠 ~700 行（#9→#30）。
- 修复方向：Read 返回"共 N 行已返回 1-M"；同文件 mtime 未变时重复 Read 提示"内容未变，可滚动回看或 grep 定位"。

### 🟠 P1-4 后台任务生命周期失控（本轮 3/5，历史 2/5 → 升级）

- 证据：019fd635 复现命令尾部 `&` + 前台 600s 超时 → 10 分钟静默阻塞（#113-114），孤儿任务不清理、后续部署被旧任务排队拖慢（#130 耗时 91s）；019fcc0e 用户关闭后台任务后不确认即重启（#206-207），且两个后台调用返回相同 task_id（#120-122，疑似工具 bug）；019fd9ec 两次 ssh 超时转后台丢输出、同模式重复犯（#79/#123）。
- 修复方向：① 前台长命令看门狗——超时 50% 且无输出时弹"转后台/终止换策略"；② 启动新后台任务时列出存活旧任务；③ 后台完成通知附"如何探测远端进程"指引；④ 排查相同 task_id 问题。

### 🟠 P1-5 用户意图误解/显式约束被自行解释（本轮 2/5，新浮现）
