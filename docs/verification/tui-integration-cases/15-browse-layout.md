# 浏览态与整体布局

按 [总目录](README.md) 的编号执行。观察实际终端帧，避免把消息已结束后的静态截图当成流式布局验证。

1. **P0-66 浏览历史时新输出不挪动视口**
   1. 在回复持续流式输出时向上滚动，记录一条静态消息的屏幕位置。
   2. 保持浏览态等待更多输出，再检查“新输出”提示并滚到底部。
   3. 核对锚点不跳动，提示在有未见内容时出现、恢复跟随后消失；输入区始终可用。
2. **P0-67 宽终端居中带与命中一致**
   1. 在宽终端显示长消息、后台任务栏、状态栏和输入区，记录各自左右边缘。
   2. 点击模型段、消息操作和最右滚动条，再缩窄并放大窗口。
   3. 核对内容带对齐、点击作用于所见目标；滚动条仍在终端最右列，正文不被盖住。
