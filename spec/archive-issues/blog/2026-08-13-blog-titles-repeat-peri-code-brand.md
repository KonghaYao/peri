# 博客标题和头部重复强调 Peri Code

**状态**：Fixed
**优先级**：中
**创建日期**：2026-08-13

## 问题描述

一批新增文章机械使用 `Peri Code` 标题前缀，并在每篇正文开头和结尾重复项目宣传链接。站点与栏目已经提供明确的项目语境，这种重复削弱了标题的信息密度，也让不同文章看起来像由同一模板生成。

## 期望改进方向

- 普通文章标题直接表达对象、机制或边界，不统一添加项目名前缀。
- 普通文章不添加固定项目宣传 blockquote，也不在结尾重复项目地址。
- 产品介绍、版本动态、跨项目比较或脱离站点传播时，才按语境保留 Peri。
- 更新博客写作规范，防止后续文章重新套用相同模板。
