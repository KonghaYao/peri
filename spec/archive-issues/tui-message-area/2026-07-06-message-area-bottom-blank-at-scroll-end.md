# 消息区滚动到底部时内容下方仍有空白


> 归档于 2026-07-20，原路径 spec/issues/2026-07-06-message-area-bottom-blank-at-scroll-end.md
**状态**：Fixed
**优先级**：中
**创建日期**：2026-07-06

## 问题描述

TUI 消息区域在内容较多并滚动到底部或向上滚动浏览历史内容时，滚动条本身可以铺满可滚动区域，但消息内容没有填满视口底部。实际表现是当前视口内最后一段可见内容下方仍然留有空白，像内容区域的底部位置计算或对齐没有贴到底部。期望滚动到底部或向上浏览时，消息内容应尽量填满消息区可见视口，不出现无意义留白。

## 症状详情

| 场景 | 现象 |
|------|------|
| 消息区滚动到底部 | 滚动条铺满，但内容下方仍有空白 |
| 消息区向上滚动浏览历史内容 | 同样出现内容下方留白，视口没有被可见消息内容填满 |
| 消息内容较多，需要滚动 | 必现 |
| 用户观察到的空白性质 | 不是滚动区域容器没铺满，而是内容没有铺满底部 |

相关但不同的历史 issue：`spec/issues/2026-07-05-message-area-viewport-empty-bottom.md` 记录的是“滚动到中间位置时视口底部空白，滚动到底部正常”；本 issue 记录的是“滚动到底部仍有空白”。

## 复现条件

- **复现频率**：必现
- **触发步骤**：
  1. 启动 TUI 并产生足够多的消息，使消息区进入可滚动状态
  2. 将消息区滚动到底部，观察最后一段消息内容与输入区/底部边界之间仍有空白
  3. 继续向上滚动浏览历史内容
  4. 观察向上滚动后的视口底部仍可能出现空白
- **环境**：macOS，ratatui-kit TUI 单路径架构

## 涉及文件

- `peri-tui/src/kit/message_area.rs` —— 消息区 ScrollView、视口裁剪与底部显示相关逻辑
- `peri-tui/src/kit/render_bridge.rs` —— 消息内容预计算为可渲染行与 wrap_map 的位置
