# L5：executor 拆分（build_* 归 Agent / RCRA loop 归 Agent / ACP 留薄壳）

**状态**：Fixed
**标签**：`ready-for-agent`、`3.0-refactor`、`agent-layer`
**优先级**：高
**类型**：重构
**创建日期**：2026-08-05
**来源**：`spec/issues/2026-08-05-peri-3.0-refactor-prd.md`（伞形 PRD）决策 21（未决项 1 推荐）

## Problem Statement

`peri-acp/src/session/executor.rs`（约 1398 行）+ `executor_helpers.rs`（约 634 行）将 session 构造、循环驱动与 ACP 协议化入口混在一起。拆法此前未定案（最大悬案）。依 §2「RCRA 循环：Receive -> Compact -> Reason -> Act，Receive 为唯一退出口」与 §0 归层判据，循环驱动属于 Agent 层 session 运行单元，装配构造属于 Agent 层 session 工厂，ACP 只保留协议化薄壳。

## Solution

拆分方案（排期时确认，以本推荐为基线）：

- **build_***：session/装配构造 → Agent 层 session 工厂（与 L2 汇合）。
- **9-phase loop（RCRA）**：→ Agent 层 session 运行器（Receive 为唯一退出口；cancel 判定/终止执行在此层，Model 执行中止由 Agent 发起）。
- **协议化入口**：executor.rs/helpers 中与 ACP 相关的入口、keepgoing 短路、事件协议化映射 → ACP 薄壳。
- Controller 只经 Runtime 的 SessionHandle 发起 run Session，不持有 loop。

## 验收标准

- [ ] RCRA loop 位于 Agent 层，Receive 为唯一退出口；cancel 最终执行权在 Agent（Cascade/Independent 判定与终止执行）。
- [ ] ACP 侧仅保留协议化薄壳（入口、映射、短路语义）。
- [ ] 行为契约测试保持绿：ARC-KEEPGOING-001（`cargo test -p peri-acp --lib executor_test` 的 keepgoing 判空三例 + 短路 push_done）、`cargo test -p peri-agent --lib stages`（空 prompt 跳过/空白 prompt 保留）。
- [ ] 身份标识 (session_id, session_epoch, turn_id, attempt_id) 在拆分后的各入口统一携带。
- [ ] turn 终态唯一（Completed/Interrupted），terminal 事件位于 turn 全部输出之后。
- [ ] 测试随迁：executor 相关测试按拆分后归属迁至对应 crate，断言语义不重写。

## 非目标

- 不改变 keepgoing/短路/取消等既有行为语义（纯拆分）。
- 不实现 §9 层间接口签名（签名定义另见伞形 PRD 未决项 5，可随本子 issue 先行在 peri-acp-types 落位）。
