# 输入区、状态栏与后台任务栏

按 [总目录](README.md) 的编号执行。分别在宽屏和低高度终端检查三块区域的显示及命中。

1. **P0-54 后台任务栏与详情一致**
   1. 启动后台 Agent 和 shell 任务，让两者分别产出可识别的实时文本。
   2. 从后台任务栏打开各自详情，并在任务完成后再次查看。
   3. 核对运行状态、耗时、详情和最终结果对应原任务；详情为空时不伪造运行记录。
2. **P0-55 状态栏反映真实执行状态**
   1. 依次制造会话准备、模型运行、取消、执行失败和正常完成状态。
   2. 观察状态栏、消息区 footer 与后台栏的提示和动画。
   3. 核对准备提示与 loading 不混淆，终态及时停止动画；错误不显示为成功或空闲假象。
3. **P0-56 待发送与已投递输入区分**
   1. 在模型运行中连续提交两条带标记的输入，保留一条未投递。
   2. 比较 composer 附近待发送区和正式消息流，再选择发送或取回一条。
   3. 核对队列计数、标记与实际状态一致；未投递项不提前冒充用户气泡，草稿不丢失。
4. **P0-57 多行及图片输入可确认内容**
   1. 在输入区编辑含换行、中文、emoji 的文本，再粘贴一张有效图片。
   2. 检查光标位置、换行、图片附着提示后提交。
   3. 核对提交前内容可读，模型收到文本与图片各一次；图片失败时显示原因并保留草稿。

## P1 补充场景

1. **P1-08 欢迎空态与首次配置提示**
   1. 用空 HOME 启动，在未建会话、准备中和已建会话三个时点抓屏。
   2. 打开模型或登录入口，随后返回主界面。
   3. 核对空态引导、配置入口和当前状态一致；首次配置失败不显示已准备完成。
2. **P1-09 历史与预测不会覆盖草稿**
   1. 输入未提交草稿，用上下键浏览历史后返回，再等待一次回答生成预测。
   2. 在空输入时按 Tab 接受预测，随后输入新字符或提交。
   3. 核对草稿可恢复、预测仅在适用时显示；接受后成为可编辑文本，不被下一帧覆盖。
3. **P1-10 补全弹层与输入区同步**
   1. 分别输入斜杠命令和文件 @mention，使用键盘选择并观察弹层。
   2. 改变终端宽度、按 Esc 关闭，再继续输入普通文本。
   3. 核对候选、选中态和插入内容一致；弹层不遮住光标，关闭后焦点返回输入区。
4. **P1-11 状态栏模型与权限段可辨**
   1. 切换模型、权限模式和工作目录，记录状态栏文字与点击位置。
   2. 点击模型段并打开快速切换层，再关闭。
   3. 核对 alias、模型名、effort 与权限标签跟随实际值；窄屏不把点击区移到别的段。
5. **P1-20 状态提示与通知不移动正文**
   1. 分别触发复制提示、退出待确认、补全提示与短时通知。
   2. 在提示出现和消失时记录状态栏及消息区的行位置。
   3. 核对提示优先级正确，通知行高度稳定；小窗口隐藏次要提示后输入仍可见。
6. **P1-22 输入区资源线与附件数量同步**
   1. 在会话中附加多张图片，并改变上下文占用与进程资源采样。
   2. 比较宽屏、低高度下的附件计数、CPU、MEM、ctx 与会话标题。
   3. 核对数字随源状态更新，窄屏按优先级隐藏装饰；实际附件不因标签隐藏而丢失。
