# 文档忽略 TUI 主路径且四个文章栏目内容不足

**状态**：Fixed
**优先级**：高
**创建日期**：2026-08-13

## 问题描述

Peri 有自己的 TUI 界面，但当前文档把环境变量、JSON 和 Provider 配置细节放在首次使用主路径上，阅读视角偏向程序员。站点虽然存在工程、产品、研究、动态四个分类入口，但栏目内容与入口叙事不足，用户难以理解每个栏目提供什么价值。

## 现状

- 文档总览与快速上手把 Provider 配置作为独立的前置技术步骤。
- Provider 指南主要教授环境变量和 JSON，而不是设置向导、Login 面板与 Model 面板。
- 产品栏目只有一篇文章，四个栏目缺少共同说明 Peri 产品、工程、研究和变化的代表性内容。

## 期望补充内容

- 首次使用改成 TUI 主路径：启动 Peri、完成设置向导、进入消息界面、提交任务、查看结果。
- Provider 连接与模型切换通过 TUI 向导和面板说明，不把环境变量作为用户主流程。
- 工程、产品、研究、动态各增加一篇有独立命题的文章，并让栏目页清楚说明阅读价值。

## 涉及文件

- `peri-cool/src/content/docs/docs/` —— 用户文档与首次使用路径。
- `peri-cool/src/content/posts/` —— 四个文章栏目。
- `peri-cool/src/pages/posts/[category]/index.astro` —— 栏目首页。
- `peri-cool/src/lib/content.ts` —— 栏目元数据。
