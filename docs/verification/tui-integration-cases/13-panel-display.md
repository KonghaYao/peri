# 面板与详情显示

按 [总目录](README.md) 的编号执行。面板全量种类与下方用例映射见 [显示覆盖矩阵](display-coverage.md)。

1. **P0-58 历史列表与预览保留选择身份**
   1. 准备多条长标题会话，打开 Threads 面板并滚动列表与只读预览。
   2. 刷新列表、切换 scope，再确认加载或删除当前选中项。
   3. 核对详情对应所选 ID 而非旧索引；预览不切换会话，确认框仍指向同一目标。
2. **P0-59 任务详情只显示所属任务**
   1. 同时运行两个名称相近的子任务与一个后台 shell，打开 Tasks 与各详情。
   2. 切换选择、查看实时与终态内容，再返回主消息区。
   3. 核对任务名、状态、输出和耗时各归其主；旧详情不会短暂显示在新选中项下。
3. **P0-60 会话资源面板标明来源与失败**
   1. 分别在无会话、会话 A 和会话 B 打开 MCP、Plugin、Hooks、Cron 面板。
   2. 注入一次查询失败并让 A 的旧响应在切换到 B 后到达。
   3. 核对面板标明数据来源与错误，B 不显示 A 的资源，失败时不冒充空结果。
4. **P0-61 配置面板保存失败不假成功**
   1. 在 Config 或 Model 面板改变设置，令持久保存失败。
   2. 观察当前行、状态栏与错误提示，再恢复保存能力并重试。
   3. 核对失败明确可见且不宣称已保存；成功后面板与状态栏显示同一实际值。

## P1 补充场景

1. **P1-12 全部面板均可打开与返回**
   1. 准备问答、子任务、后台 shell 与 Goal 夹具，再依次打开常规设置和资源面板。
   2. 通过各自实际入口打开 Threads、AskUser、SubAgentDetail、ShellDetail、Goal 等详情。
   3. 逐个核对标题、空态、滚动与关闭后焦点；无白屏、明显裁切或旧面板残影。
2. **P1-13 设置类面板窄屏可编辑**
   1. 在窄屏中打开 Model、Login、Config 和 Theme，浏览长名称及多行描述。
   2. 使用键盘与鼠标切换选项，取消一次编辑并保存另一次。
   3. 核对高亮、实际值和提示一致；Unicode 截断不切半字，取消不改真实配置。
3. **P1-14 工作面板状态区分空、加载与失败**
   1. 分别让 Agent、Tasks、MCP、Plugin、Hooks、Cron 和 Workflow 返回空、慢响应、错误。
   2. 在每种状态打开面板并切换 tab 或选中项。
   3. 核对加载不冒充空、错误可见且能重试；旧结果不遮盖新查询。
4. **P1-15 信息面板数值与来源明确**
   1. 打开 Status、Memory、Goal 与 Threads，记录当前会话和工作目录。
   2. 切换会话并刷新面板，比较标题、数值与详情。
   3. 核对会话相关值随会话变化，宿主配置仍标明宿主来源；无值时不显示旧数据。
