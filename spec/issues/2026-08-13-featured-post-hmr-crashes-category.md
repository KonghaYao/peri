# 新增代表文章时开发服务器短暂崩溃栏目页

**状态**：Fixed
**优先级**：高
**创建日期**：2026-08-13

## 问题描述

开发服务器同时接收栏目代表文章配置和新 MDX 文件时，内容集合可能短暂仍是上一次同步结果。栏目页立即按严格规则查找代表文章，找不到时抛出“代表文章不存在”，导致文章总览与对应栏目返回错误。

## 症状详情

- 研究栏目报告 `栏目“研究”的代表文章不存在：research/long-session-study`。
- 随后的完整静态构建可以发现并生成该文章，说明文件存在，失败发生在开发态内容同步窗口。
- Collection ID 是否带 `.mdx` 也不应影响代表文章匹配。

## 复现条件

- **复现频率**：开发服务器热更新窗口可复现。
- **触发步骤**：同时新增代表文章文件，并更新栏目元数据指向它。
- **环境**：Astro dev 内容集合热更新。

## 涉及文件

- `peri-cool/src/lib/content.ts` —— 代表文章解析。
- `peri-cool/src/pages/posts/index.astro` —— 文章总览。
- `peri-cool/src/pages/posts/[category]/index.astro` —— 栏目页。
- `peri-cool/src/lib/content.test.ts` —— 回归测试。
