# 流式回答与工具

按 [总目录](README.md) 的编号执行。工具夹具要能延迟结束事件并提供成功、失败两类确定结果。

1. **P0-13 推理、正文与工具保持事件顺序**
   1. 让模型依次输出推理、正文、工具启动、工具结果和后续正文。
   2. 检查消息区按事件顺序分段，工具后文字不插到工具前，不合并不同助手消息。
   3. 等待终态并重载历史；工具与推理呈完成态，原有顺序仍可读。
2. **P0-14 新 prompt 不丢在途工具结果**
   1. 首轮工具卡开始后暂缓 ToolEnded，提交第二条本地 prompt。
   2. 释放工具结束事件，确认旧卡片显示真实输出和完成态，新气泡位于旧卡片之后。
   3. 等首轮结束、第二轮开始后复查；工具不应停在运行态，顺序不应变化。
3. **P0-15 队列投递不丢在途工具结果**
   1. 首轮工具运行期间投递一条队列输入，随后才送达该工具的结束事件。
   2. 检查旧工具卡完成输出位于新用户气泡之前。
   3. 核对队列输入只显示、执行各一次；旧工具的晚到结果不能覆盖新回合或让新工具卡误变为完成态。
4. **P0-16 工具失败可见且能继续对话**
   1. 驱动工具返回确定的失败结果，再让助手输出后续说明。
   2. 检查工具卡显示失败状态和错误摘要，后续正文排在卡片之后。
   3. 等回合结束后提交新 prompt；界面不持续转圈，新回复正常出现。
5. **P0-17 流式取消保留已显示输出**（[issue](../../../spec/issues/2026-10-09-cancel-loading.md)）
   1. 在推理或正文已有部分内容时取消，让取消终态与剩余流片段相邻到达。
   2. 确认已显示文本保留并冻结，loading 结束且内容不再增长。
   3. 启动下一轮并送达旧片段或重复终态；旧内容不得追加到新回答。
