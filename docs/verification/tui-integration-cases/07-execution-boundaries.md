# 执行、历史与故障边界

按 [总目录](README.md) 的编号执行。以下场景来自仍需真实使用验收的 active issue；用例是目标，不表示当前实现已通过。

1. **P0-32 历史未结束工具不能复活**（[issue](../../../spec/issues/2026-10-06-p0-remove-session-runtime-state-restoration.md)）
   1. 准备仅有 ToolStarted、没有结果的旧会话，退出进程后重新加载。
   2. 查看历史工具卡并手动续聊，记录模型与工具请求。
   3. 核对缺失结果静态可辨、不转圈；加载不自动执行旧工具，续聊按新请求正常运行。
2. **P0-33 新会话冻结的 Agent 目录可用**（[issue](../../../spec/issues/2026-10-07-p0-agent-catalog-empty-in-frozen-prompt.md)）
   1. 在内置子 Agent 启用的配置下创建全新会话，并捕获首次模型请求。
   2. 检查冻结提示词的 Agent 目录，再发出需要委派的任务。
   3. 核对目录列出可用候选而非空占位；关闭子 Agent 后新会话不再列出这些候选。
3. **P0-34 预算耗尽后显式输入可续聊**（[issue](../../../spec/issues/2026-10-06-p0-agent-budget-interruption.md)）
   1. 用低限额夹具耗尽推理预算，保留已完成的工具结果和会话历史。
   2. 检查失败提示中的预算类型及已用/上限，再在同会话显式发送新任务。
   3. 核对旧工具不重放、旧计数不被暗中清零；新任务获得明确准入并能继续执行。
4. **P0-35 内部失败有可定位诊断**（[issue](../../../spec/issues/2026-10-06-p0-agent-internal-error-diagnostic-loss.md)）
   1. 分别注入两种原因不同的内部失败，保留会话、运行身份与默认日志。
   2. 检查 TUI 错误提示，并按同一执行身份查对应诊断记录。
   3. 核对日志区分阶段、操作和有序原因链，合成路径及响应正文保真；取消和预算阻塞不误报未知错误。
5. **P0-36 准备阶段取消能结束 loading**（[issue](../../../spec/issues/2026-10-09-cancel-loading.md)）
   1. 让系统 MCP readiness 或模型前 middleware 持续等待，在出现 loading 后取消。
   2. 等待服务端匹配终态，再提交下一轮普通请求。
   3. 核对旧 hook 已退出、loading 消失且下一轮可运行；不得只在界面假装结束执行。
6. **P0-37 并发工具准入不制造未知结果**（[issue](../../../spec/issues/2026-10-06-tui-execution-failures.md)）
   1. 让模型在同一回合发起四个不同文件的 Read，并记录每个 invocation 身份。
   2. 等待全部工具与助手终态，查看卡片及持久执行证据。
   3. 核对四次读取分别完成、不因冗余准入报 StaleRevision；未知副作用不得被重试伪装成功。
