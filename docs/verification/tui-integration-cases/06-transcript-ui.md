# 消息区与覆盖层

按 [总目录](README.md) 的编号执行。用固定终端尺寸与长内容制造可重复的滚动位置。

1. **P0-28 长消息滚动不丢内容**
   1. 生成超过一屏的用户、助手、工具和子任务记录，滚到中部。
   2. 继续追加流式输出，再用滚轮、拖拽、端点点击及键盘浏览首尾。
   3. 核对阅读位置稳定、滚动条与内容同步，无白屏、跳行或重复条目。
2. **P0-29 主区与详情滚动条一致**
   1. 在同一尺寸下让主消息区和 subagent 详情都超过视口，记录主区位置。
   2. 打开详情，比较两处轨道与滑块，再滚动详情并关闭弹窗。
   3. 核对外观与命中方式一致、主区位置不变，最右列正文不被滚动条覆盖。
3. **P0-30 弹窗遮罩不穿透**
   1. 在消息区准备可点击工具卡、在输入框保留草稿，再打开面板和弹窗。
   2. 分别点击弹窗按钮、边缘及遮罩，按 Esc 逐层关闭。
   3. 核对仅最上层响应；工具卡、输入提交和底层面板不误触，草稿与焦点仍可用。
4. **P0-31 极窄终端仍可完成主路径**
   1. 把终端缩到约 40×8，启动一轮对话并打开面板或弹窗。
   2. 用键盘关闭覆盖层、继续提交，再放大终端。
   3. 核对小尺寸下输入、状态与回复仍可读且能提交；放大后不白屏、不残留遮罩或丢失正文。
5. **P0-81 滚到已载入窗口顶端加载更早历史**（[issue](../../../spec/issues/2026-10-13-transcript-shrink-history-pagination.md)）
   1. 用已协商历史分页能力、历史长于首屏的会话启动，记下首屏中一条自有条目（含工具卡）的屏幕行；稀疏首屏形态（继承前缀与摘要之间存在旧历史缺口）的会话单独再跑一次。
   2. 在空闲会话里（没有回复在流式输出）用滚轮与键盘滚到已载入窗口顶端，等更早一页并入；随后在页响应返回前分别切到另一会话、以及对本会话执行 rewind。
   3. 核对更早内容出现在原顶端上方、与既有条目无重复且不整段重排；被记录的那条自有条目仍在原屏幕行（缺口在视口下方填补时视口整体不动）；切会话 / rewind 后迟到的页不出现，也不改写新窗口的游标与取页提示。
