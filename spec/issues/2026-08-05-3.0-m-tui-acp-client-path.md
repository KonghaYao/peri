**最后核查**：2026-08-22

## 最新情况（2026-08-22）

主链完成状态保持，且 stdio 已整体接入统一 `run_acp_server` / `handle_request`，不再保留 typed handler 业务分支。当前部署差异只有显式边界：transport pump 继续兼容精确行 `{"type":"cancel"}`（无 sessionId、全 session 兜底取消；标准 `session/cancel` 不变）；stdio 装配设置 `stdio_command_filter=true`，使 slash `rewind` / `clear`（含 alias）不投影、不拦截并 fall-through 进 agent，TUI/print 与 `session/rewind*` RPC 不受影响。命令面（mcp/list、cron/list、thread/list 等）、C 类豁免与 e2e 基线仍未收（见「遗留清单」节）。

## Problem Statement

TUI 进程内嵌整个控制面与 server：直连 `run_session_loop`、直接实例化存储、v2_tx 双轨（见事件链路子 issue）；print 直连 `run_session_loop`，与 TUI 不经同一协议路径；stdio server 宿主层未定。违反 §7「全部客户端（TUI/CLI/stdio/IDE/print）一律经 ACP」与 §8「TUI 只经 ACP 拿数据，不触碰业务层」。

## Solution

TUI 收敛为 View 层：cli = 启动接口（装配 View 与 ACP 客户端，不承载业务）；TUI 与 print 一律经 ACP 客户端拿数据；print 为同层轻量渲染客户端（无界面，输出文本），经 ACP 走 ephemeral session（不造 sessionless）。TUI 内嵌 server 迁出为独立 ACP host 装配（cli 启动，部署形态：层 ≠ 进程，ACP Host = 部署单元）；stdio host 归 ACP 层。多客户端 attach 采用多读者 + 单 writer lease（writer 唯一可提交输入/取消；协议级扩展另立 issue）。

## 验收标准

- [ ] TUI 不再直连 `run_session_loop`，交互主路径（prompt/cancel/session）全部经 ACP client/transport（ARC-BOUNDARY-001 强化成立）。
- [ ] print 经 ACP（ephemeral session），行为与 TUI 一致；`-p` 模式下 keepgoing/取消语义不回归（ARC-KEEPGOING-001 相关 e2e 保持绿）。
- [ ] TUI 内嵌 server 迁出：TUI 进程不再持有控制面；ACP host 由 cli 装配启动。
- [ ] stdio host 位于 ACP 层（部署装配点），依赖方向符合 §0。
- [ ] 多读者 + 单 writer lease 生效（观察者只读、操作者唯一）。
- [ ] e2e 行为基线（Seam 1）全绿：`e2e/tests/scenarios`、smoke、subagent 场景。

## 非目标

- 不改变 TUI 渲染与交互设计（仅迁出控制面与传输路径）。
- 不做多客户端 attach 的协议级扩展（策略先行，协议扩展另立 issue）。
- 不合并 transport（stdio 与 in-process 的去留由事件链路子 issue 的 canonical contract 决定）。

## 遗留清单（主链收口后登记，随命令面落地收）

- **C 类豁免（conf 边 1，2026-08-06 收紧后）**：`app/service_registry.rs`、`app/cron_state.rs`、`app/mod.rs`（面板直持 McpClientPool/CronScheduler + tick 驱动）、`kit/*`（service_snapshot/atoms/panels 数据源直读）、`cli_plugin.rs`（36 处 plugin/marketplace 直读，操作已改经 send_raw_request）、`launch.rs`（plugin 数据源加载块 + teardown hooks）、`cli_print.rs`（仅 `Resources::open()` thread_store 协议面输入）、`thread/mod.rs`（re-export）
- **预留端口（trait 已声明、impl 已就位、命令面未落地）**：`McpPoolPort::snapshot/shutdown`、`CronSchedulerPort::list_tasks/toggle/remove`、`PluginManagerPort::cleanup/marketplace_add/remove/update/snapshot`——供 mcp/list、cron/list、host/shutdown、plugin marketplace 命令面

- **面板数据源**：「面板数据全部经 ACP」需 cron/list、mcp/list、thread/list 命令面落地
