# L2：中间件链装配 build_agent 迁至 Agent 层 session 工厂（ARC-MIDDLEWARE-001 同步迁）

**状态**：Ready for agent
**标签**：`ready-for-agent`、`3.0-refactor`、`agent-layer`
**优先级**：高
**类型**：重构
**创建日期**：2026-08-05
**来源**：`spec/issues/2026-08-05-peri-3.0-refactor-prd.md`（伞形 PRD）决策 5、16

## Problem Statement

中间件链的唯一装配点是 `peri-acp/src/agent/builder.rs`（约 1200 行），这是 peri-acp 直依赖 6 个业务 crate（含 peri-middlewares）的主因，违反 §0 依赖规则。`SubAgentMiddleware` 唯一构造点（`builder.rs:436-470`）亦在此。ARC-MIDDLEWARE-001 规定「链的唯一事实源是 ACP builder」——事实源位置随重构必须同步迁移，禁止中间态双事实源。

## Solution

将链装配迁至 Agent 层 session 工厂：session 初始化时构建 MiddlewareChain（数据自 Resources），事实源自 `peri-acp/src/agent/builder.rs` 迁入（ARC-MIDDLEWARE-001 同步迁）。链序本身是行为契约，不得按名称/便利性/局部需求重排。迁移后 peri-acp 不再依赖业务 middleware crate。

## 验收标准

- [ ] MiddlewareChain 装配位于 Agent 层 session 工厂，session 初始化时构建。
- [ ] 链序与迁移前完全一致（装配顺序契约测试保持绿）。
- [ ] `peri-acp` 不再依赖业务 middleware crate（§0 边，CI 依赖门通过）。
- [ ] `SubAgentMiddleware` 构造点随迁，无遗留 ACP 侧装配。
- [ ] ARC-MIDDLEWARE-001 文档的 Verify 指向更新为 Agent 层工厂；规则正文不变。
- [ ] 单元测试随迁（builder 相关测试语义保持，不重写断言）。

## 非目标

- 不改变中间件链顺序与中间件行为（纯归位）。
- 不合并/拆分 middleware crate（分片属后续演进，不在本子 issue）。
