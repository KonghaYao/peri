# 研究记录骨架

按任务规模选用下列内容，不要求固定章节数量。给读者的结论与给后续 agent 的复核信息可以分别呈现，但影响解释的限制不能被删去。未测量项目填“不可用”及原因，不填零。

## 结论与研究问题

先回答要支持的决策，区分观察、改进候选和未验证解释。结论中的数字引用本次运行产物，并保留必要的总体范围。

## 来源与口径

- 来源、读取方式、运行时间、schema/解析器/规则版本；原始路径按需在本机保留。
- 快照或指纹及其覆盖对象；过滤条件、时区、半开边界和时间字段。
- 总体、统计单位与抽样单位；纳入、去重、排除依据和各自数量。
- 指标定义、分子/分母、阈值；连续段、重复身份和未知状态的处理。
- 可重复命令与机器产物路径；指纹不替代这些复现信息。

## 数据质量与可比性

列出解析失败、缺失、冲突、孤立记录、继承/双写与无法识别的污染。解释总数间的差额及受影响的指标。比较时并列两侧样本量、分母、版本与质量；口径不兼容时明确不可比。

## 发现与证据

每项发现保留：

- 稳定 ID 和 `observed` / `candidate` / `unverified` 状态。
- 本次观测值与分母，或无法量化的原因；避免把定向案例比例外推到总体。
- 从源记录提取并逐条回查的完整 ID、范围/指纹和有界上下文；默认仅安全摘要。
- 案例选择方法、已阅读数量、唯一会话数与跨标签重叠。
- 后续活动、反例和替代解释；哪些初始判断被撤回。

## 改进队列

保留可读说明；供 agent 接续时同时输出结构化条目。示意字段如下，按领域调整，避免复制两套统计事实：

```json
{
  "id": "stable-finding-id",
  "status": "candidate",
  "problem": "触发条件与可观察影响",
  "metricsRef": "本次产物中的指标及分母位置",
  "evidence": [{"source": "来源身份", "threadId": "完整标识", "messageId": "完整标识"}],
  "counterEvidence": [],
  "limitations": ["尚缺哪些证据"],
  "entryPoints": ["当前代码、配置或流程入口"],
  "nextVerification": "能证实或推翻候选的复现/检查",
  "successCriterion": "什么可观察结果才算改进"
}
```

## 验证与局限

记录实际执行的命令、退出状态及有效用例或样本数量，区分计算正确性、案例复核和修复效果。记录报告和队列中所有证据引用的解析检查结果，修正不存在或指向错误来源的引用。说明未验证项、缺失观测来源与推广范围；没有对照设计时不得将变化归因为修复。
