# 阻塞交互与弹出层显示

按 [总目录](README.md) 的编号执行。AskUser 的现行可交互入口是 Panel；旧 PopupKind 只保留空渲染路由，不能作为成功截图。

1. **P0-62 审批弹窗动作与风险清晰**
   1. 触发需审批的工具，检查弹窗的调用名、参数、可用动作和默认焦点。
   2. 点击正文、边框与遮罩，再明确选择拒绝或允许。
   3. 核对非动作区域不批准；提交后动作不可重复，弹窗不会让背景输入被点击。
2. **P0-63 OAuth 弹窗可读且能回到会话**
   1. 触发登录 OAuth 流程，打开包含授权地址与操作提示的弹窗。
   2. 在窄屏中查看、复制或打开链接，再取消或完成认证。
   3. 核对复制或打开的目标是完整授权地址，错误可见；关闭后会话与输入草稿保留。
3. **P0-64 确认与 Rewind 目标不串位**
   1. 在多个会话或历史检查点中选定一个目标，打开 Confirm 或 Rewind 弹窗。
   2. 在弹窗期间刷新底层列表、改变选中项，再明确取消或确认。
   3. 核对弹窗显示并作用于冻结目标；取消不执行，确认不因旧索引操作另一条记录。
4. **P0-65 AskUser 面板问题与选项完整**
   1. 触发多题、多选或自定义输入的 AskUser，打开现行问答面板。
   2. 在标准与窄屏尺寸逐项查看、选择并提交，再加载历史记录。
   3. 核对问题与选项可读、选择态明确；历史只显示已答内容，不复活可提交控件。
5. **P0-89 认证子视图与配置草稿的窄屏、长 URL 和双语显示**（Login 认证子视图不是
   `PopupKind::OAuth`）
   1. 在窄而矮的终端打开 Login plan 认证子视图，注入长授权 URL；滚动到末尾后分别点击
      `Open browser`、`Copy link`、`Cancel sign-in`，并检查点击背景面板不会穿透。
   2. 等待授权期间在 en 与 zh-CN 间切换；核对 URL、提示、按钮、状态与错误均为当前语言完整
      文案，不出现原始 key 或半截多字节字符；`Copy link` 复制完整 URL。
   3. 在 Login Edit 与 Model 的 Responses contextWindow 行内编辑上重复窄屏检查：
      用键盘和鼠标分别聚焦/切换字段、选择类型与认证方式、勾选档位、点击 Confirm/Save/Cancel，
      结果一致；点击空白、边框、分隔线与滚动条不触发动作。Model 普通右栏 K/V 行点击先聚焦
      再执行键盘同义动作；底部“管理 Provider”按钮与 Ctrl+L 等价，窄屏下仍可点击。向 choice、
      按钮或 Confirm 粘贴多行文本不得 panic 或写入隐藏字段；保存前如有被清洗的输入，核对
      保存被阻断。Model 的窗口数值 editor 与 Model 文本 editor 对多行/控制字符粘贴整段拒绝：
      文本不变、错误可见、修正前阻断保存，修正后可继续保存。认证子视图 Esc 只取消登录并
      回到编辑态，再按 Esc 才放弃草稿并停止等待。
   4. 在窄屏下分别构造 `Checking`、`Unchecked`、`SignedOut`、查询失败与作用域不一致：
      保存时 `Checking` 只出现等待提示、不写红字，其余状态出现对应文案且推荐动作可执行；
      已登录且草稿身份为空时一次保存成功，无“请先登录”；过期只显示访问令牌与自动刷新文案。
      Ctrl+R 重载到不同 store/account 后不显示旧目标的“已登录”，也不会自动采用旧身份。

## P1 补充场景

1. **P1-16 下载进度弹窗显示终态**
   1. 从 Theme 面板启动下载，分别驱动进度、成功与失败。
   2. 在下载中缩放终端并尝试关闭弹窗。
   3. 核对进度与结果不混淆，失败原因可见；关闭后不残留遮罩或假运行状态。
2. **P1-17 模型快速切换层锚定状态栏**
   1. 点击状态栏模型段打开快速切换层，观察其位置与选中行。
   2. 分别用鼠标和上下键切换，按 Esc 关闭并改变终端宽度重试。
   3. 核对弹层仍锚在模型段附近，选择后状态栏更新；点击别处不切错模型。
3. **P1-18 主题与语言切换不留旧样式**
   1. 在长消息、工具卡和打开的面板上切换主题及中英文语言。
   2. 滚动离开再返回，打开弹窗并调整终端宽度。
   3. 核对正文、代码背景、状态色和可见文案同步更新；缓存不复用旧主题样式。
