# 消息区有换行内容时向上滚动，视口底部约 20% 为空白

**状态**：Open
**优先级**：中
**创建日期**：2026-07-05

## 问题描述

消息区内容包含代码块或长行（需要换行）且内容较长（几百行以上）时，从底部向上滚动到中间位置，视口底部约 20% 的区域显示为空白。滚动到底部时内容正常显示，但一旦向上滚动到中间位置，底部就开始出现空白区域。纯文本消息（无换行）不受影响。

## 症状详情

| 条件 | 现象 |
|------|------|
| 内容几百行，含代码块/长行 | 向上滚到中间时，底部 ~20% 空白 |
| 滚动到底部 | 正常显示 |
| 纯文本（无换行） | 正常 |
| 内容几十行 | 未触发（需几百行） |

- **复现频率**：100% 必现
- **环境**：macOS，kit 架构

## 复现条件

- **复现频率**：必现
- **触发步骤**：
  1. 让 agent 产生包含代码块或长行输出的对话，累计几百行以上
  2. 滚动到底部确认内容完整显示
  3. 向上滚轮滚动到对话中间位置
  4. 观察视口底部出现约 20% 空白区域
- **环境**：macOS，kit 架构

## 涉及文件

- `peri-tui/src/kit/message_area.rs` —— 消息区视口裁剪 `viewport_clip()` + ScrollView 渲染逻辑
