# 长会话与资源稳定性

按 [总目录](README.md) 的编号执行。固定二进制、终端尺寸和负载，记录 CPU 时间、延迟、RSS 与缓存计数；不得用单次进程百分比替代差分证据。

1. **P0-41 长历史淘汰缓存后仍可操作**（[issue](../../../spec/issues/2026-10-06-p0-tui-architecture-optimization.md)）
   1. 准备长历史和长 Markdown 内容，滚动、选择并复制中部文本。
   2. 追加流式输出使派生缓存淘汰，再返回原位置并调整窗口宽度。
   3. 核对内容、高度、选择和复制与淘汰前一致，无跳滚、漏字或错位命中。
2. **P0-42 长流式与多子任务保持响应**（[issue](../../../spec/issues/2026-10-06-p0-tui-architecture-optimization.md)）
   1. 固定负载依次运行空闲、长正文流式、多个子任务和长详情场景。
   2. 每阶段操作输入、滚动和详情，同时采集帧延迟、CPU 时间与缓存占用。
   3. 核对交互可完成且缓存有界；同负载对比记录资源变化，不以编译通过冒充性能验收。
3. **P0-43 长任务后新请求不随历史显著退化**（[issue](../../../spec/issues/2026-10-06-p0-dev-peri-high-cpu-memory.md)）
   1. 在隔离会话累积大量已完成工具和模型请求，保留完整历史证据。
   2. 分别在短历史与长历史下提交同类新任务，采集提交耗时、CPU 与内存峰值。
   3. 核对新任务正常完成，旧工具不重放；对增长斜率与持久数据体积给出可复核记录。

## P2 补充场景

1. **P2-02 大历史预览切换释放派生内容**（[issue](../../../spec/issues/2026-10-06-tui-perf-memory-scan.md)）
   1. 在 Threads 面板预览含大量消息的会话，再切换到另一会话预览。
   2. 关闭面板并重复打开，记录内容、交互延迟和内存曲线。
   3. 核对预览无串会话或残留；旧派生内容可释放，失败加载不留不可见大对象。
