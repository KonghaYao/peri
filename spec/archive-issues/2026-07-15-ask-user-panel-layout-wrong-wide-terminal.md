# AskUserQuestion 面板：宽终端下布局混乱——文本提前换行 + 分隔线错位 + 面板过高

**状态**：Fixed
**优先级**：中
**创建日期**：2026-07-15

## 问题描述

AskUserQuestion 内联面板在宽终端（>120 列）下整体布局混乱：问题文本和选项 label/description 在不必要的位置提前换行，分隔线长度与面板宽度不匹配，面板高度远大于实际内容需要，视觉上呈现为文字、分隔线、留白错位交织。

## 症状详情

| 项目 | 详情 |
|------|------|
| 触发条件 | 终端宽度 >120 列时必现；终端 <100 列时反而不明显 |
| 渲染形式 | 内联 Panel（MessageArea 和 InputArea 之间），非 Popup |
| 分隔线 | `"─".repeat(60)` 固定 60 列宽，在 120+ 列终端中明显过短 |
| 文本换行 | 问题文本、选项 label、选项 description 均提前折行——即使实际富余宽度足以单行显示 |
| 面板高度 | 因不必要的文本折行导致行数膨胀，面板占据过多垂直空间 |
| 整体效果 | 分隔线位置和文本位置相互错位，布局看起来被"压缩"在左侧 60-80 列范围内 |

## 复现条件

- **复现频率**：必现
- **触发步骤**：
  1. 在宽终端（120+ 列）中启动 peri-tui
  2. 与 agent 对话，让 agent 调用 AskUserQuestion 工具（问题选项 label 有中等长度文本即可）
  3. 观察内联面板的渲染效果
- **环境**：macOS，终端 >120 列

## 涉及文件

- `peri-tui/src/kit/panels/ask_user.rs` —— 面板渲染逻辑，使用 `WRAP_WIDTH = 80` 固定换行宽度（:39），分隔线 `"─".repeat(60)` 固定 60 列（:491），与面板实际 `Constraint::Fill(1)` 动态宽度不匹配
- `peri-tui/src/kit/popups/ask_user_popup.rs` —— 旧 Popup 版本也有同样的 `"─".repeat(60)` 问题（:252），但当前已迁移为空渲染
