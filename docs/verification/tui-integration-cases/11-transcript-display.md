# 消息内容显示

按 [总目录](README.md) 的编号执行。每个标记同时检查实时显示和最终归档，避免仅靠事件记录推断屏幕正确。

1. **P0-45 用户、助手与推理各有清晰位置**
   1. 发送含中文与 emoji 的输入，让模型先推理、再分片输出两段不同正文。
   2. 在流式中和终态后分别查看消息区，展开及折叠推理。
   3. 核对用户、推理、正文顺序稳定，同一消息不按 chunk 重复成行，正文不被折叠吞掉。
2. **P0-46 工具状态在原位置更新**
   1. 分别触发运行中、成功和失败的 Read、Bash、Edit 工具卡。
   2. 比较启动、结束和历史重放后的标题、状态符号、结果摘要及耗时。
   3. 核对同一调用仅有一张卡；失败有明确文字，成功不会一直转圈，结果不被新卡覆盖。
3. **P0-47 工具分组仍可逐项核对**
   1. 连续执行多个成功工具，并在其中加入一个失败工具与一个子任务调用。
   2. 展开收束后的成功组，查看每项工具，再检查子任务的最近工具行。
   3. 核对隐藏数量准确、每项仍可访问；失败不藏在成功组中，子工具不挂到别的父卡。
4. **P0-48 系统事件与任务摘要不冒充用户**
   1. 产生普通系统通知、错误提示、System Reminder、回合分隔线和 Todo 进度。
   2. 在实时消息区及历史重放中核对各行前缀、层级和相对顺序。
   3. 确认提醒可展开、错误原因可见；这些内容都不呈现为新用户气泡或助手正文。
5. **P0-49 问答与审批记录显示终态**
   1. 触发一次待回答问题和一次审批，分别完成或拒绝。
   2. 查看消息区 pending 选项、完成结果、所选项标记并手动折叠。
   3. 核对已答记录默认可读，折叠只缩成结果行；历史记录不可再次提交旧响应。
6. **P0-50 Markdown 流式与终态一致**
   1. 流式输出含标题、列表、表格、引用、链接及跨 chunk 代码围栏的正文。
   2. 在围栏未闭合和闭合后抓屏，再让回合终止并重载历史。
   3. 核对语法结构、代码背景和换行稳定；终态解析不丢字、不把围栏内空行当断点。
7. **P0-51 大输出可辨完整性并复制**
   1. 让工具产生超过内联行数的输出，让错误摘要也超过预览高度。
   2. 展开工具、打开可用详情，并从正文、工具头、diff 和错误处复制文本。
   3. 核对截断可辨；协议提供详情时能核对全文，否则明确标注不可用；复制不含视觉行号或省略符。
8. **P0-52 不可信文本不能破坏终端**
   1. 在模型和工具输出中加入 ANSI 控制符、OSC 链接、双向控制符与宽字符。
   2. 观察显示、移动光标、滚动并复制该区域。
   3. 核对控制序列不执行、不污染后续行；中英文宽度对齐，复制内容不带终端控制字符。
9. **P0-53 实时与历史显示同一结果**
   1. 完成含用户、推理、工具、子任务和错误提示的回合，保存终态屏幕。
   2. 重启并加载该会话，展开相同条目并比较可见内容。
   3. 核对结果、失败状态、分组及顺序一致；历史记录不重新动画或伪装为当前执行。

## P1 补充场景

1. **P1-06 图片与链接预览不抢正文**
   1. 输出 Markdown 图片、普通链接和坏链接，移动鼠标进入与离开命中区域。
   2. 等待预览出现，再切换链接并点击打开。
   3. 核对预览目标与当前链接一致；旧预览及时消失，坏链接不遮挡正文或误打开别处。
2. **P1-07 折叠选择跨更新保持**
   1. 手动展开一个工具和一段推理，再继续让同回合输出新 chunk。
   2. 滚动离开视口、改变窗口宽度，随后返回原条目。
   3. 核对用户选择仍保持，折叠状态不因动画、缓存淘汰或终态翻转突然复位。
3. **P1-19 图片预览覆盖层能安全退出**
   1. 让消息含有效图片链接与不可预览资源，分别悬停、点击并打开图片覆盖层。
   2. 在覆盖层中改变窗口尺寸、关闭并回到原消息位置。
   3. 核对图片对应当前链接，失败有提示；关闭不吞正文点击或留下旧图残影。
4. **P1-21 KeepGoing 按钮与运行态一致**
   1. 让 Agent 完成一轮，再查看 footer 中的 KeepGoing 按钮并点击两次。
   2. 在继续运行和防抖期观察按钮位置与禁用样式。
   3. 核对只启动一次继续执行，运行中按钮不冒充可点击；不新增空用户气泡。
5. **P1-23 Skill 与 Todo 工具呈现正确**
   1. 分别触发 SkillTool 和 TodoWrite，保留各自运行中及完成时的屏幕。
   2. 展开工具并比较技能名称、待办变更摘要和结果。
   3. 核对两者仍遵循统一状态符号与折叠规则；不把技能正文或完整待办数据塞入标题。
6. **P1-24 工具族摘要与 diff 可读**
   1. 分别运行 Read、Grep、Web、Bash、Edit 及一个未知 MCP 工具。
   2. 对比标题中的对象、结果后缀和 Edit 展开后的差异行。
   3. 核对已知工具按自身语义显示，未知工具使用通用名称；diff 行号不侵占正文宽度。
7. **P1-25 流式模式终态显示等价**
   1. 用同一响应夹具分别以 Streaming、Block、None 模式完成对话。
   2. 在中途与终态抓屏，记录每种模式的可见增量与最终内容。
   3. 核对模式只改变更新节奏；终态正文、推理、工具顺序和折叠结果保持一致。
