# M：事件链路 canonical（事件三层化 + v2_tx 双轨下线）

**状态**：Ready for agent
**标签**：`ready-for-agent`、`3.0-refactor`、`events`
**优先级**：中
**类型**：重构
**创建日期**：2026-08-05
**来源**：`spec/issues/2026-08-05-peri-3.0-refactor-prd.md`（伞形 PRD）决策 9、10；既有 issue `2026-07-25-event-identity-diverges-across-dual-delivery-paths.md`

## Problem Statement

Agent 层事件目前存在三通道（render/state/observe）+ v2_tx 双轨直连 TUI（绕过 ACP caps 门控）。同一事件可经双轨投递，身份字段（message_id、source_agent_id）在转换中被替换为默认值或 None，两条路径各自维护 mapper 与 suppress 规则——事件身份与语义随路径漂移。ARC-EVENT-001 要求新增事件覆盖完整链路，双轨使该验证无法成立。

## Solution

按 §9 事件链路契约收敛为单事实源：`Agent →(emit 业务事件) Runtime →(聚合路由) Controller →(过滤) ACP →(协议化) TUI`；v2_tx 双轨直连下线，TUI 只经 ACP 拿数据。事件携带 turn_id + agent_id；session_id 由 Runtime 聚合时按 session 补打；同 session 事件带单调 session_seq；terminal 事件必须位于该 turn 全部输出事件之后。canonical envelope 契约沿用 `2026-07-25-event-identity-diverges-across-dual-delivery-paths.md` 定义的 contract（本子 issue 不重复规定，落地其 contract 并实现双轨下线）。

## 验收标准

- [ ] v2_tx 双轨直连移除，TUI 事件仅经 ACP 协议化路径（caps 门控生效）。
- [ ] 事件身份跨链路一致：turn_id/agent_id 全程保留；session_id 由 Runtime 补打；session_seq 单调。
- [ ] 同一 (session_id, turn_id, sequence) 在 TUI 不产生重复业务效果（工具卡/SystemNote 不重复）。
- [ ] `2026-07-25-event-identity-diverges-across-dual-delivery-paths.md` 的验收标准全部达成（含 mapper 穷尽匹配、无 Default 伪装缺失身份）。
- [ ] `2026-07-18-events-v2-mapper-removal.md` 与 `2026-07-18-executor-event-retirement.md` 的退役目标在本子 issue 完成后达成（删除 v2 mapper 桥接与双轨事件定义）。
- [ ] ARC-EVENT-001 Verify 更新为单链路验证。

## 非目标

- 不改变事件协议 wire format（`peri/agent_event` 等 ACP 事件形态保持兼容）。
- 不改造 EventBus 满时丢弃的可靠性交付（属 `2026-07-25-control-boundary-events-can-be-dropped.md`）。
