# M：Resources 层落地（新 crate + SqliteThreadStore 迁入 + 存储操作归位）

**状态**：Ready for agent
**标签**：`ready-for-agent`、`3.0-refactor`、`resources-layer`
**优先级**：高
**类型**：重构
**创建日期**：2026-08-05
**来源**：`spec/issues/2026-08-05-peri-3.0-refactor-prd.md`（伞形 PRD）决策 6

## Problem Statement

外部系统访问通道散落各层：`ThreadStore` trait 与 `SqliteThreadStore` 实现在 peri-agent（约 20 处引用），TUI 两处直接实例化存储（`peri-tui/src/app/mod.rs:79`、`peri-tui/src/acp_stdio/init.rs:113`）；dispatch 中的存储操作位于 ACP/TUI；peri-lsp / peri-workflow 游离在分层主链之外。违反 §0「来源：外部系统数据，访问通道归 Resources；持有按生命周期」。

## Solution

新建 `peri-resources` crate（内含 peri-config / peri-sessions 子模块）：peri-config 直操配置文件；peri-sessions 直操 sqlite（`SqliteThreadStore` 实现迁入）；MCP 状态维持、HITL broker、secret 一并收口。以 context 形式提供给 Agent / Middleware / Controller。TUI/ACP 不再实例化存储，改经 Resources context；dispatch 存储操作迁 Controller。peri-lsp / peri-workflow 作为 resource 实现接入（context 包装），不参与分层主链。

## 验收标准

- [ ] `peri-resources` 创建，内含 peri-config / peri-sessions 子模块。
- [ ] `SqliteThreadStore` 实现位于 peri-sessions；约 20 处引用改经 Resources context，TUI 两处实例化点移除。
- [ ] peri-acp / peri-tui / peri-agent 不再直接实例化存储。
- [ ] dispatch 存储操作位于 Controller（归层判据：组合多源决策归 Controller）。
- [ ] peri-lsp / peri-workflow 经 context 包装接入，Middleware 经 context 使用、不直接依赖。
- [ ] 存储相关测试随迁且保持绿（`peri-agent/src/thread/sqlite_store_test.rs` 语义不重写）。
- [ ] §0 依赖方向 CI 门通过（新增 crate 边不越层）。

## 非目标

- 不改变 sqlite schema 与持久化格式（纯归位）。
- 不迁移 provider 配置读取语义之外的配置逻辑（provider 工厂拆分见伞形 PRD 未决项 3）。
