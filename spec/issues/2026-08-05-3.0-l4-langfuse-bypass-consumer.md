# L4：Langfuse 观测迁为事件流旁路消费者

**状态**：Ready for agent
**标签**：`ready-for-agent`、`3.0-refactor`、`observability`
**优先级**：中
**类型**：重构
**创建日期**：2026-08-05
**来源**：`spec/issues/2026-08-05-peri-3.0-refactor-prd.md`（伞形 PRD）决策 17

## Problem Statement

Langfuse 观测实现（约 3700 行）内嵌在 `peri-acp/src/langfuse/`，观测逻辑参与业务链路，违反 §0「消费：旁路观测走独立通道，不参与业务链路」。观测采集点被绑定在 ACP 层，无法覆盖 Model 层 token/调用、Agent 层 stage/turn、Controller 操作等跨层信息。

## Solution

将观测重构为旁路消费者：bridge 是事件流旁路消费者，装配在 Controller 侧宿主，不承担 Controller 职责。采集点分散各层（Model 层 token/调用、Agent 层 stage/turn、Controller 操作、ACP 事件）；观测事件随主事件流走，在协议化前分支给 bridge；关联靠身份牌（session_id + turn_id + agent_id），不改变业务链路。业务链路不含观测逻辑。

## 验收标准

- [ ] bridge 从 peri-acp 迁出，装配在 Controller 侧宿主；`peri-acp/src/langfuse/` 不再内嵌观测实现。
- [ ] 观测事件在主事件流协议化前分支给 bridge，业务链路无观测逻辑。
- [ ] 采集点覆盖 Model/Agent/Controller/ACP 四层（token、stage/turn、操作、事件）。
- [ ] 既有 Langfuse 行为保持：batcher 不丢事件（`2026-08-05-langfuse-batcher-drops-during-slow-flush.md` 复验）、subagent attribution 正确（`2026-08-05-langfuse-subagent-attribution-*` 复验）。
- [ ] 单元测试随迁（`peri-acp/src/langfuse/bridge_test.rs` 语义保持），并补充协议化前分支用例。

## 非目标

- 不改变 Langfuse 上报格式与观测语义（纯归位 + 采集点扩展）。
- 不实现新的观测产品能力（trace viewer 等）。
