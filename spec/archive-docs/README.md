# 文档归档

本目录保存**已完成实现计划**与**被后续架构取代的设计文档**，仅作历史记录。归档不代表其中实现细节仍与当前代码一致；当前规范请从 `docs/standards/`、`docs/design/` 与 `spec/` 现役目录查找。

- `design/` — 被后续架构取代的 `docs/design/` 设计文档（索引见 `docs/design/archive.md`）。
- `superpowers/` — superpowers 工作流中已完成的实现计划（`plans/`）与已落地的设计（`specs/`）。

与 `spec/archive-issues/`（issue 归档）不混用。
