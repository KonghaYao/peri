# 审批与问答

按 [总目录](README.md) 的编号执行。夹具需能明确区分审批结果、问答内容与所归属的运行请求。

1. **P0-24 审批通过后工具只执行一次**
   1. 在默认权限模式触发需审批的工具，检查弹窗显示工具及参数。
   2. 选择一次允许，等待工具结果和回合终态。
   3. 核对弹窗关闭、真实结果可见、工具只执行一次；审批响应只进入当前请求，loading 正常清除。
2. **P0-25 审批拒绝不执行工具**
   1. 触发同类审批并选择拒绝或取消。
   2. 检查工具没有实际副作用，消息区显示拒绝结果，助手能继续或结束，输入焦点恢复。
   3. 发送新 prompt；旧审批不应再次出现，刚才的工具不得被补执行或转交给新回合。
3. **P0-26 AskUser 答案交给原请求**
   1. 让 Agent 发起含多个选项的问题，在面板选择一项并提交。
   2. 检查面板关闭，实际响应内容与所选项一致，后续回答引用该答案。
   3. 核对只提交一次；另一会话或后续回合不能收到此答案。
4. **P0-27 交互关闭与旧请求隔离**
   1. 在审批或问答弹窗打开时取消原回合，随后启动新回合。
   2. 送达旧交互通知，并对最上层弹窗按 Esc、Enter 或点击遮罩。
   3. 核对旧弹窗不重现、旧响应不进入新回合；背景面板和输入框不被穿透触发。

## P1 补充场景

1. **P1-05 内部续跑的审批归属正确**（[issue](../../../spec/issues/2026-10-08-async-execution-chain-fixes.md)）
   1. 让后台结果或定时任务触发内部续跑，并在首步要求审批或 AskUser。
   2. 响应交互后再取消或结束该次内部执行。
   3. 核对弹窗可操作、响应只交给该次执行；其终态不清除另一轮的 loading。
