# L3：subagent 创建统一迁至 Agent 层 SessionFactory

**状态**：Fixed
**标签**：`ready-for-agent`、`3.0-refactor`、`agent-layer`
**优先级**：高
**类型**：重构
**创建日期**：2026-08-05
**来源**：`spec/issues/2026-08-05-peri-3.0-refactor-prd.md`（伞形 PRD）决策 3、5、17

## Problem Statement

subagent 创建逻辑分散在 4 条执行路径（spawner / execute_fork / execute_bg / build_agent）外加 ACP `/bg` 斜杠命令，整体约 4600 行，构成 `SubAgentMiddleware`（24 字段）这一 v2 越层最重模块。创建语义（thread 持久化、父子链、frozen copy、agent_status 更新）不统一，且创建权在 Middleware/ACP 而非 session 所属的 Agent 层。

## Solution

在 Agent 层建立统一入口 `SessionFactory::spawn_subagent(parent, config)`，4 条执行路径与 `/bg` 命令全部改经它：建 thread（经 Resources 存储，`parent_thread_id` 挂父子链，thread_id = agent_id）、建 session（transcript 绑定存储 with_persistence、frozen data copy）、运行 + 结束（更新 agent_status）。Middleware 只声明工具与发起意图，不持有创建实现。

## 验收标准

- [ ] `SessionFactory::spawn_subagent(parent, config)` 为唯一 subagent 创建入口，位于 peri-agent。
- [ ] spawner / execute_fork / execute_bg / build_agent 四条路径与 ACP `/bg` 斜杠命令全部改经统一入口。
- [ ] subagent 必有持久化 thread（parent_thread_id 父子链正确落库）；frozen data 从父 session copy，不重新读取磁盘。
- [ ] agent_status 更新语义与迁移前一致（运行中/结束状态）。
- [ ] 既有 subagent 测试随迁且保持绿（`peri-middlewares/src/subagent/` 下 `*_test.rs`）。
- [ ] `SubAgentMiddleware` 字段数显著收敛（管理权移出后瘦身），不再持有创建实现。

## 非目标

- 不改变 subagent 业务行为（fork/bg/内置 agent 语义不变）。
- 不合并消息类型（MessageType 更名属伞形 PRD 其他决策，另行落地）。
