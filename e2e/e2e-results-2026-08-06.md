## 问题清单

### 问题 1：tmux server 故障（影响前 3 个测试，疑似环境问题）

- 现象：`model-switch` 报 `can't find pane: tui-test-1786021672145-ppula9`；`plugin-uninstall-no-freeze`、`ask-user-question` 报 `no server running on /private/tmp/tmux-501/default`。
- 特征：三个测试均 10~17s 即失败（正常启动等待就需 5s+），失败点都在 `captureScreen`，属于基础设施不可用而非断言失败；从第 4 个测试（plugin.test.ts）起 tmux server 自动重建，后续测试全部恢复正常。
- 疑因：测试开始前存在残留 tmux session（`tui-test-1786021625001-jc9l1a`，内含挂起的 `dev.sh`，21:07:06 启动），期间 tmux server 被终止（代码中无 kill-server 逻辑，tui-tester/setup/helpers 均无）。残留 session 在 21:08 前后退出，server 恢复。
- 建议：运行 e2e 前清理残留 `tui-test-*` session；排查残留 dev.sh 挂起原因。
